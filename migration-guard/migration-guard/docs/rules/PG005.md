# PG005: set an existing column `NOT NULL`

`ALTER TABLE ... ALTER COLUMN ... SET NOT NULL` is reported because it may
scan existing rows while holding a strong table lock. On PostgreSQL 12 and
later, a validated `CHECK (column IS NOT NULL)` can allow the scan to be
skipped; the rule remains conservative until schema replay proves that guard.

Reference: [ALTER TABLE](https://www.postgresql.org/docs/current/sql-altertable.html).

Safer rollout:

```sql
ALTER TABLE users ADD CONSTRAINT users_email_nn CHECK (email IS NOT NULL) NOT VALID;
ALTER TABLE users VALIDATE CONSTRAINT users_email_nn;
ALTER TABLE users ALTER COLUMN email SET NOT NULL;
```

The rule cannot currently know table size, null distribution, existing checks,
or application traffic.

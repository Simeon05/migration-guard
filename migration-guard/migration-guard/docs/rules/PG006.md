# PG006: create index without `CONCURRENTLY`

This rule reports `CREATE INDEX` unless the statement uses `CONCURRENTLY`.
PostgreSQL documents that ordinary index creation can block writes; the
concurrent form reduces blocking but must run outside a transaction.

Reference: [CREATE INDEX](https://www.postgresql.org/docs/current/sql-createindex.html).

Use `CREATE INDEX CONCURRENTLY` in a separately managed migration when the
deployment tool does not wrap it in a transaction. The rule cannot currently
infer transaction wrapping from the SQL file alone.

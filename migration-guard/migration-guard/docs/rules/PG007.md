# PG007: `CREATE INDEX CONCURRENTLY` inside a transaction

Reports concurrent index creation while an explicit transaction is open.
PostgreSQL rejects this form because concurrent index builds must run outside a
transaction block. See [CREATE INDEX](https://www.postgresql.org/docs/current/sql-createindex.html).

Configure migration tooling to disable its transaction wrapper for this file.
The current detector cannot infer framework-level implicit transactions.
